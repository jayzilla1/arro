# Arro

**Uninsured, not out of options.**

Arro helps uninsured people find the most affordable care nearby and see what they'll likely pay before they walk in.

This is the Phase 1 clickable prototype: a mobile-first web app with mock data. Everything a person enters stays in their own browser. Prices shown are estimates, not quotes.

## Run it on your computer
Open `index.html` in a browser, or in VS Code use the "Live Server" extension and click **Go Live**.

## Files
- `index.html`: all the screens
- `styles.css`: brand colors, fonts and layout
- `app.js`: navigation, swipe cards and mock data
- `screenshots/`: phone-size screenshots of each screen
